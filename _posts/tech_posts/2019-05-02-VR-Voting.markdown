# VR Voting |  Tunisian Elections, 2019
Educational Virtual Reality Experience for Democracy International - [www.democracyinternational.com](www.democracyinternational.com)

_________________________________

This game aims to educate youth on the voting process by walking them through the different steps of an election day in Tunisia. 

Players can interact with various elements of the environment (Ballot, Pen, ID Card..) to unlock the next steps.

Using Unity 3D, Steam VR sdk, HTC Vive.

+ VR Application Developer: Ahmed Jerbi
+ 3D Designer: Raed Ghanja 

____________________________________________________


### Tools:

+ Unity 3D
+ SteamVR SDK, HTC Vive
+ C#
