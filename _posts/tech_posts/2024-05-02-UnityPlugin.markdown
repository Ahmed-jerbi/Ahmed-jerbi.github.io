# Unity - VIOSO plugin (2020)
Integrating multi-projector warp and blend calibration data into the Unity rendering pipelines.

The implementation uses the [VIOSO API](https://docs.vioso.com/integration/vioso-warpblend-api) as a native plugin to ingest data and create a post-processing effect for multiple Unity cameras.

The plugin allows multi-perspective and dynamic eyepoint projections into calibrated surfaces, used notably in simulations screens, CAVEs, Immersive rooms..etc

_____________________________________________________

### Asset store 
[Download the Integration plugin from the Unity Asset Store](https://assetstore.unity.com/packages/tools/integration/vioso-warping-blending-integration-for-multi-projection-166403)

### Tools:

+ Unity SRP, URP, HDRP pipelines
+ C# .NET
+ GLSL : OpenGL Shading Language
