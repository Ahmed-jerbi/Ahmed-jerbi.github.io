# Academic Project | Green IoT Watering System 

Smart & automated watering via connected sensors and voice commands

_____________________________________________________

The smart plant is connected to the University Virtual Assistant (IVA) and can interact and execute commands:

- Voice Recognition and dialogue (Virtual Assistant)
- Pull data from nnected Sensors 
- Schedule and automate tasks
- Draw real-time visualizations 

### Tools:

+ RaspberryPi 3
+ STM32
+ BLE
+ IBM cloud
+ NodeRed
