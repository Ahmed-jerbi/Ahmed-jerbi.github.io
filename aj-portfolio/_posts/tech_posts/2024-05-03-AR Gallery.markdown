# Augmented Election Data
Educational Experience for Democracy International - [www.democracyinternational.com](www.democracyinternational.com)

________________________________________

Augmenting a booklet that summarizes the 2019 Tunisian election results in an interactive 3D data visualisation. 

A project in collaboration with [Rafaa Seddik](https://www.behance.net/rafaaseddik)

Download the Android application [.apk via this link](https://drive.google.com/open?id=1eobFTyXPp3xZlcncE_DbqqNN283rWIPe)

### Tools: 
+ Unity
+  ARCore
+  Vuforia SDK
+  C#
